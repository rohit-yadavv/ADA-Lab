Function Strassen(A, B):
Input: Matrices A and B of size n x n
Output: Matrix C of size n x n, where C = A * B

    1. Base Case:
       If n == 1:
           Return [[A[0][0] * B[0][0]]]

    2. Divide Matrices:
       Partition A and B into four submatrices of size n/2 x n/2:
           A = [A11, A12; A21, A22]
           B = [B11, B12; B21, B22]

    3. Calculate 7 Products (using submatrices):
       M1 = (A11 + A22) * (B11 + B22)
       M2 = (A21 + A22) * B11
       M3 = A11 * (B12 - B22)
       M4 = A22 * (B21 - B11)
       M5 = (A11 + A12) * B22
       M6 = (A21 - A11) * (B11 + B12)
       M7 = (A12 - A22) * (B21 + B22)

    4. Combine Submatrices:
       C11 = M1 + M4 - M5 + M7
       C12 = M3 + M5
       C21 = M2 + M4
       C22 = M1 - M2 + M3 + M6

       Combine C11, C12, C21, C22 to form the result matrix C.

    5. Return C
